Board ini adalah Development Board Microcontroller berbasis ESP32 (dengan dukungan chip tambahan TQFP32/ATmega) yang dirancang khusus untuk pembelajaran, riset, serta pengembangan proyek Internet of Things (IoT) dan sistem tertanam (embedded system) di lingkungan Universitas Nahdlatul Ulama Blitar.

Deskripsi Produk / Fitur Utama

Board pembelajaran IoT berbasis mikrokontroler canggih yang memadukan konektivitas nirkabel, manajemen waktu presisi, serta fleksibilitas antarmuka sensor dalam satu platform praktis.
